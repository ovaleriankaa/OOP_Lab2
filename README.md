# Лабораторна робота 2

## Слободян Валерія ІПС-32
## Опис проєкту
Java-додаток для роботи з XML-документами в межах лабораторної роботи №2 (варіант 10 - "Пиво"). Проєкт реалізує створення та валідацію XML-файлу за схемою XSD, розбір документа трьома способами (SAX, DOM, StAX), сортування отриманої колекції об'єктів за допомогою `Comparator`, а також XSL-перетворення структури XML із групуванням елементів. Робота програми супроводжується логуванням та покрита модульними тестами.

## Предметна область (Варіант 10)
Кореневий елемент XML-документа - `Beer`.

## Основний функціонал
- Опис структури даних за допомогою XSD-схеми з використанням простих і комплексних типів, переліків, граничних значень, атрибутів та типу `ID`.
- Валідація XML-документа на відповідність XSD-схемі.
- Парсинг XML-документа за допомогою SAX, DOM та StAX парсерів з ініціалізацією колекції Java-об'єктів.
- Сортування колекції об'єктів за допомогою інтерфейсу `Comparator`.
- Перетворення XML-файлу за допомогою XSL зі зміною структури та розбиттям списку на підсписки за обраною характеристикою.
- Логування процесу виконання програми.
- Модульне тестування.

## Технології
- Java
- Maven
- XML / XSD / XSL (SAX, DOM, StAX)
- Log4j2
- JUnit
